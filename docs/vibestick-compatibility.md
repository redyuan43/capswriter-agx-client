# VibeStick compatibility

## Cardputer-Adv

Use CapsWriter GUI `v1.0.16-agx-client` or newer with VibeStick
`cardputer-adv-v0.1.26`.

This pairing enables the Cardputer Wi-Fi keyboard, pointer, and device-mapping
bridge APIs. Cardputer-Adv uses OTA board `cardputer_adv`; it is not compatible
with MiniJoy Bluetooth firmware or its `stickc_plus_minijoy_bt` OTA channel.
