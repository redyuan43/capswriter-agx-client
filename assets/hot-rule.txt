# 专名：把 ASR 的大小写/拆分变体收敛到唯一正确写法。
# Tailscale 实测 16 条正确 / 15 条错写，是错写率最高的专名。
# 一条规则覆盖 tailscale(全小写) / TailScale(驼峰) / Tail Scale(拆开) / TAILSCALE(全大写)。
# 2026-09-21 加边界（agx 式，连 - 与 _ 一起排除）：原版无边界会把 tailscale.com、
# capswriter-tailscale-yyy 这类域名/路径也改掉（3897 条语料回归实测踩中）。
(?<![/.@A-Za-z0-9_-])[Tt][Aa][Ii][Ll]\s*[Ss][Cc][Aa][Ll][Ee](?![./A-Za-z0-9_-]) = Tailscale
(?<![A-Za-z])tcale(?![A-Za-z]) = Tailscale

# GitHub：一条覆盖 github / Github / GITHUB / Git Hub。
# 前后必须是真的自然语言边界：排除 / . @ 与字母数字，否则会把
# ~/github/capswriter-agx-client、https://github.com/... 这类路径与域名一起改掉。
(?<![/.@\w])[Gg][Ii][Tt]\s*[Hh][Uu][Bb](?![/.\w]) = GitHub
